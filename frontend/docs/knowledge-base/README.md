# База знаний

Этот каталог - временный frontend-owned источник пользовательской документации для внутренней wiki приложения.

Пока отдельный раздел "База знаний" не реализован в UI, статьи хранятся как Markdown рядом с frontend-документацией. Будущий wiki-модуль должен использовать эти материалы как исходный контент, а не переписывать смысл заново.
