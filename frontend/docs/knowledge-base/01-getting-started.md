# 01. Панель управления / Cockpit Overview

Добро пожаловать в AirlineSim! Ваша главная рабочая область — это Дашборд с интерактивной картой мира. Отсюда вы можете управлять всей своей сетью и наблюдать за полетами в реальном времени.

## Интерактивная карта мира
Карта отображает ваш домашний аэропорт (стартовый хаб), проложенные маршруты и плавно перемещающиеся иконки самолетов, выполняющих рейсы в реальном времени.

## Панель показателей
Вверху бокового меню отображается сводка ключевых параметров авиакомпании:
1. **Баланс**: Свободные средства компании. Покупка самолетов, оплата топлива и сборы списываются сразу. Доходы зачисляются по мере завершения полетов.
2. **Цена топлива**: Текущая рыночная стоимость тонны авиатоплива. Обновляется циклически, влияя на себестоимость рейсов.
3. **Флот**: Общее число самолетов в собственности компании.
4. **Алерты**: Количество активных предупреждений системы (например: риск банкротства, несовместимость ВПП, отсутствие расписания у маршрутов).

## Рекомендуемый шаг
Используйте карточку «Рекомендуемый шаг» под картой в качестве подсказки. Этот помощник динамически проведет вас по всей цепочке запуска компании от покупки первого самолета до отслеживания полетов.
