# 06. Телеметрия полетов / Flight Telemetry

Симуляция полетов в реальном времени работает на основе математического моделирования траектории. Все полетные показатели рассчитываются детерминированно «на лету» без нагрузки на базу данных.

## Разделение состояния и фазы
- **Состояние (status)**: Персистентное поле (`scheduled`, `boarding`, `in_flight`, `completed`, `cancelled`). Хранится в базе данных, является источником истины для финансовых проводок и физического положения бортов.
- **Фаза (phase)**: Расчетное поле для отображения в интерфейсе. Рассчитывается динамически на основе времени вылета/прилета и дистанции.

## Временная шкала полета
Блок-тайм от выкатки (gate-out) до заезда к гейту (gate-in) делится на сегменты:
```
[Scheduled] -> Boarding (за 30 мин до вылета) -> Taxi Out -> Takeoff -> Climb -> Cruise (эшелон) -> Descent -> Landing -> Taxi In -> Deplaning (15 мин после прилета) -> Arrived
```

## Синтез физических параметров
При просмотре активного рейса симулируется полетная телеметрия:
- **Высота**: Растет в наборе высоты, фиксируется на эшелоне (FL260/FL320/FL360/FL390 в зависимости от дальности полета) и снижается до 0 при посадке.
- **Скорость**: Равна 0 до вылета, держится около 28 км/ч на рулении, возрастает при разбеге до крейсерской скорости ВС и падает до нуля при парковке.
- **Топливо**: Рассчитывается как сумма резерва (12% от расхода) и топлива на полет. Топливо расходуется в воздухе по мере приближения к цели.

## Клиентская интерполяция
На карте дашборда положение самолета плавно интерполируется на клиенте по параметру `air_progress` (от 0 до 1) без постоянных запросов к серверу.
