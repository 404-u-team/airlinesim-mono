# Ночные операции

Для MVP ночным считается местное время `23:00-06:00`. Schedule preview проверяет местное время вылета и прилета по timezone каждого аэропорта.

Если аэропорт не работает ночью, конфликт блокирует активацию расписания. Отсутствующая или некорректная timezone показывается отдельным предупреждением.
