# Пропускная способность и плановый запас

Slot capacity MVP показывает физическую дневную пропускную способность ВПП и плановые использования вашей авиакомпании.

- до 80%: нормальная загрузка;
- 80-100%: плановый запас заканчивается;
- выше 100%: новое расписание нельзя активировать.

Это planning headroom, а не глобально подтвержденное распределение слотов между всеми авиакомпаниями.
